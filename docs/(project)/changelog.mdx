### Changed

- The LLM docs page moved from `/docs/pipeline/llm-openrouter` to [LLM layer & providers](/docs/pipeline/llm-providers)
  (the old URL remains as a pointer).
- Automatic mock mode now checks the **selected provider's** key; `/api/ready` and the startup log report the
  provider; the platform dashboard shows `provider · model`; the LLM cache key includes the provider.
- The pipeline never loads retracted events, and account resolution ignores retracted directory companies and
  contacts ([Pipeline stages](/docs/pipeline/stages)).
- Deploy validation requires the selected provider's key and model instead of always the OpenRouter pair.
- ADR-0009 is extended by ADR-0017 (the model rule now covers every provider); ADR-0005 is extended by ADR-0018.

### Fixed

- `PATCH /platform/data/connectors/:id` no longer clears the connector's cron schedule when `schedule` is omitted from
  the body (send `""` or `null` to clear it).
- `GET /platform/data/companies/:id` returned 500 (untyped `jsonb_build_object` parameter).
- The commit endpoint and the import wizard now report the invalid-ratio limit before "nothing to commit", matching
  the worker.

### Security

- `HTTP_FEED` connectors reuse the crawler's SSRF guard on every request, refuse redirects and cross-host pagination,
  and can read only `CONNECTOR_*` env vars as auth secrets ([Security](/docs/architecture/security)).
- Provider API keys live only in env or Secrets Manager; `.env.example` ships empty keys.

## v0.1.0 — 2026-09-24

The first implementation of the approved plan.

### Platform & infrastructure

- pnpm + Turborepo monorepo with `apps/web`, `apps/api`, `apps/worker` and the packages `shared`, `core`, `db`, `llm`,
  `pipeline`, `engine`, `dataset` and `seed`.
- One validated environment schema (`packages/shared/src/env.ts`), a single `.env.example` with every local, AWS
  runtime and AWS deploy key, automatic mock mode when no OpenRouter key is set, and optional AWS Secrets Manager
  loading at boot.
- Env-driven drivers: MinIO/S3 storage, SMTP/SES mail, Postgres TLS with the RDS CA bundle, Redis TLS.
- Docker Compose stack (Postgres 16, Redis 7, MinIO from `quay.io`, Mailpit, one-shot migrate + seed, API, worker, web)
  with healthchecks and configurable host ports (`*_HOST_PORT`).
- Multi-stage Dockerfiles using `turbo prune`. The API and worker run TypeScript via `tsx` (no bundling). The web image
  uses Next.js standalone output.
- AWS CDK app and deploy scripts in `infra/` (deploy-ready work, not deployed).

### Identity, tenancy & security

- Auth with argon2id passwords, a 15-minute access JWT and a rotating opaque refresh token (7 days) in `HttpOnly`
  cookies, refresh-token reuse detection (family revocation), lockout after 10 failures, rate limits, password reset.
- Single-use, hashed, 72-hour invitations for org admins (Super Admin) and teammates (Org Admin).
- RBAC with five roles and 25 permissions (`packages/shared/src/rbac.ts`), default-deny route guards, SDR ownership
  rules, and a lead-visibility setting behind a feature flag.
- Application-level tenant isolation (membership-derived `org_id`, 404 on cross-tenant access). Super Admins get 403 on
  tenant routes and see public-level data and aggregates only through allow-list DTOs.
- SSRF-protected website crawler, magic-byte upload validation, prompt-injection-aware prompting, CSV-injection-safe
  exports, log and audit redaction.

### Knowledge & onboarding

- Org onboarding: basics, website crawl, document uploads (PDF, DOCX, Markdown, text) through presigned URLs, pasted
  text, products, plans, policies with Public/Internal visibility, chunking and Postgres FTS indexing.
- AI knowledge profile generation (editable, versioned), AI-suggested ICPs, custom ICPs.
- Industry signal templates (managed by the Super Admin) cloned into orgs, custom signals with match instructions,
  keywords, negative keywords and weights.
- Activation queues the first pipeline run.

### Intelligence pipeline & scoring

- Pipeline runs (manual, scheduled every 6 hours, on activation): keyword and window prefilter, batched LLM matching and
  extraction (`signal.match`), account resolution through a synthetic company directory, dedupe and upsert of leads,
  evidence and timeline entries, BANT+ scoring.
- Idempotency through `org_event_evaluations` (signals-hash aware) and unique matches and leads. One active run per org.
  Budget guard (60 calls) with `PARTIAL` runs. Live progress over SSE.
- BANT+ scoring: LLM-judged budget, need and timeline, and deterministic authority, ICP fit and signal strength (30-day
  half-life). HOT/WARM/COLD bands, heuristic fallback, "Why this score?" rationales.
- OpenRouter client over `fetch`, with the model only from `OPENROUTER_MODEL`, `json_schema` structured output with
  fallback, Zod validation with a repair retry, retries with backoff, a Redis response cache, per-process concurrency
  limit, and `llm_calls` telemetry including cost.
- Seven versioned prompts with deterministic mocks. Evaluation harness `pnpm eval:pipeline` over a 60-item gold set.

### CRM, outreach, dashboards & audit

- Leads grid (6 per page, filters, sorts, search), lead detail with evidence and score breakdown, stages with optimistic
  locking, assignment, race-safe claim, bulk actions, notes, contacts, tasks, CSV export, re-scoring.
- Outreach: AI drafts for email, WhatsApp and call scripts. Email really sent through the worker (Mailpit/SES) with
  delivery status. WhatsApp, call and meeting through deep links and manual logging, with automatic stage transitions.
- Org dashboard (KPIs, funnel, weekly bands, leads by signal, team leaderboard, channel effectiveness, "My stats" for
  SDRs, 60 s cache) and Super Admin platform dashboard (aggregates only).
- Append-only audit trail (database trigger), PLATFORM and ORG scopes, field-level diffs with redaction, a safety-net hook
  for any unaudited mutation, daily retention job.

### Demo data

- Synthetic, fictional dataset: 5 orgs across Healthcare, Automotive, Semiconductors, Renewable Energy and Logistics,
  300 events, 130 companies, 274 contacts, 30 signal templates, and about 190 leads pre-scored with the mock LLM, with
  simulated CRM history. A sixth org, Voltedge Mobility, is left `INVITED` with a local-only demo invite link.
