---
title: Known limitations
description: An honest list of what SelloEasy v0.1 does not do yet, what is simplified, and what is planned.
---

SelloEasy v0.1 is a complete vertical slice: onboarding, knowledge, ICPs and signals, the AI pipeline, scoring, CRM,
outreach, dashboards and audit all work end to end. Several things are deliberately simplified or not built yet. This
page lists them so evaluators and operators are not surprised.

## Data and intelligence

| Limitation                              | Details                                                                                                                                                                                                                                                                                                                                                       | Planned direction                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **No live news sources out of the box** | The seed loads a synthetic 300-event corpus. More data arrives only through Super Admin [imports](/docs/platform-data/importing) or [connectors](/docs/platform-data/connectors-and-ingestion) (`HTTP_FEED` for any feed in template v1, `DEMO_FEED` for the bundled 60-event reserve). There is no RSS, news-API or webhook adapter that maps other formats. | Format-mapping connectors (RSS, news APIs) that emit template v1                          |
| **Synthetic contacts / directory**      | Accounts and contacts come from a synthetic company directory standing in for an enrichment provider. No real enrichment, no scraping.                                                                                                                                                                                                                        | Enrichment provider integration (contact source `ENRICHED` exists in the schema)          |
| **Keyword FTS retrieval**               | Knowledge retrieval uses Postgres full-text search, not embeddings. Weaker for paraphrases.                                                                                                                                                                                                                                                                   | pgvector + embeddings ([ADR-0004](/docs/decisions/0004-fts-over-vector-retrieval))        |
| **Prefilter needs keywords**            | Events without any active-signal keyword never reach the LLM, even if relevant. Negative keywords are only applied by the matcher, not the prefilter.                                                                                                                                                                                                         | Smarter prefilter (FTS ranking, per-signal thresholds)                                    |
| **Budget-limited runs**                 | Runs stop matching at about 60% of `PIPELINE_MAX_LLM_CALLS_PER_RUN` and fall back to heuristic scores when the budget is exhausted (`PARTIAL`)                                                                                                                                                                                                                | Configurable split, per-org budgets                                                       |
| **Model-dependent quality**             | Matching and scoring quality depend on the configured provider and model (`LLM_PROVIDER` and its `*_MODEL`). No evaluation results are recorded yet.                                                                                                                                                                                                          | Run and publish [evaluation](/docs/pipeline/evaluation) results, nightly evaluation in CI |
| **No manual score override**            | Scores can be re-computed but not overridden by hand                                                                                                                                                                                                                                                                                                          | Audited manual override with a reason                                                     |
| **No OCR**                              | Scanned PDFs without a text layer fail with "No extractable text found"                                                                                                                                                                                                                                                                                       | OCR step for image-only PDFs                                                              |
| **Crawler is simple**                   | No JavaScript rendering (SPAs yield little text), 25 pages at depth 2, same host only                                                                                                                                                                                                                                                                         | Headless rendering, sitemaps                                                              |
| **English only**                        | Prompts and FTS configuration (`'english'`) assume English content                                                                                                                                                                                                                                                                                            | Language detection, multilingual FTS                                                      |

## Platform data

| Limitation                                   | Details                                                                                                                                                                                                                                                     |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Append / retract only**                    | Stored events, companies and contacts cannot be edited in place. Fix data by rolling back the batch and importing a corrected file ([ADR-0016](/docs/decisions/0016-retract-instead-of-delete-for-rollback)).                                               |
| **Retracted records still block re-import**  | Duplicate detection also matches retracted events (same source + `external_id`, same URL or same content hash), and the unique indexes include them. A corrected record must use a new `external_id` and `source_url` and differ in content to be accepted. |
| **Rollback keeps tenant leads**              | Rolling back a batch never deletes leads, matches or accounts orgs already created from it; it only stops future runs from matching the events. Any `COMMITTED` batch, including the seed batch, can be rolled back.                                        |
| **No review step for connectors**            | Connector runs insert valid rows directly. The invalid-ratio guard and the AI quality gate apply to file imports only; invalid rows are reported, never inserted.                                                                                           |
| **Cost under-reported for direct providers** | OpenAI and Anthropic do not return cost. Without `LLM_PRICE_INPUT_PER_MTOK` / `LLM_PRICE_OUTPUT_PER_MTOK`, their calls are recorded with cost 0.                                                                                                            |
| **Estimated totals**                         | Unfiltered explorer lists on tables above 50 000 rows show a `pg_class.reltuples` estimate, which also counts retracted rows ([ADR-0018](/docs/decisions/0018-hybrid-offset-keyset-pagination)).                                                            |
| **Anthropic adapter lightly tested**         | The Anthropic adapter is covered by request-shaping unit tests with a fake `fetch`, not by live evaluation runs.                                                                                                                                            |

## Product

| Limitation                                          | Details                                                                                                                                                   |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **WhatsApp, voice and meetings are not integrated** | Deep links (`wa.me`, `tel:`, Calendly) plus manual logging. Only email is sent ([ADR-0006](/docs/decisions/0006-deep-links-for-whatsapp-voice-calendly)). |
| **No email tracking or replies**                    | No open or click tracking, sequences, or reply ingestion. Delivery status is "handed to provider", not "delivered".                                       |
| **One org per user**                                | Enforced when accepting invites. The schema supports multiple memberships, but the UI and API assume one.                                                 |
| **Stage order not enforced**                        | Any stage can be set manually. Only `LOST` requires a reason.                                                                                             |
| **No soft delete**                                  | Deletes are hard (captured in the audit log with a `before` snapshot)                                                                                     |
| **Lead visibility toggle hidden**                   | `ASSIGNED_ONLY` works, but changing it needs `FEATURE_LEAD_VISIBILITY_TOGGLE=true` ([ADR-0011](/docs/decisions/0011-lead-visibility-setting))             |
| **No audit CSV export**                             | Audit logs are browsable and filterable in the UI and API only                                                                                            |
| **Super Admin cannot inspect tenant data**          | By design ([ADR-0010](/docs/decisions/0010-superadmin-public-data-boundary)). Support needs an org admin.                                                 |
| **No notifications**                                | No in-app or email notifications for new hot leads, assignments or due tasks                                                                              |
| **Dashboard cache**                                 | Org dashboards are cached for 60 s. Very recent changes can take a minute to show.                                                                        |

## Platform, security and operations

| Limitation                                 | Details                                                                                                                                                                                                                                         |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No Row-Level Security**                  | Tenant isolation is enforced in application code only ([ADR-0007](/docs/decisions/0007-app-level-tenancy-before-rls))                                                                                                                           |
| **No upload antivirus scanning**           | Uploads are size-limited and magic-byte-checked, but not scanned for malware                                                                                                                                                                    |
| **Presigned uploads do not enforce size**  | Size is checked when the URL is requested and when the file is processed, not by the presigned PUT itself                                                                                                                                       |
| **Crawler DNS rebinding**                  | DNS is validated before each request, but the resolved IP is not pinned for the connection                                                                                                                                                      |
| **Audit table protected by trigger only**  | The append-only trigger blocks updates and deletes, but the application role is not yet restricted to `INSERT, SELECT`                                                                                                                          |
| **No OpenTelemetry**                       | `OTEL_*` flags are reserved. No traces or metrics exporter is wired ([Observability](/docs/operations/observability)).                                                                                                                          |
| **Reserved config keys**                   | `JWT_REFRESH_SECRET` (refresh tokens are opaque) and `LEADS_PAGE_SIZE_DEFAULT` (page size is the constant 6) are validated but unused                                                                                                           |
| **No mock-mode pipeline E2E in CI**        | Unit, API-integration and Playwright E2E suites exist; the Playwright happy flow needs a running stack, so CI runs the unit/integration suites only                                                                                             |
| **No lint step in CI**                     | CI runs typecheck, tests, dataset validation, docs/env checks, `cdk synth` and image builds, but no ESLint configuration exists yet                                                                                                             |
| **Not deployed to AWS**                    | Deploy-ready by design, not deployed ([AWS deployment](/docs/operations/aws-deployment))                                                                                                                                                        |
| **Backend runs via tsx**                   | Slower cold start and larger images than bundled builds ([ADR-0013](/docs/decisions/0013-tsx-runtime-no-bundling))                                                                                                                              |
| **Single-region, single-Redis**            | No multi-region story. Redis is a single node (ElastiCache in AWS).                                                                                                                                                                             |
| **Per-process LLM concurrency**            | `LLM_MAX_CONCURRENCY` is enforced per process, not globally across replicas                                                                                                                                                                     |
| **Capability self-healing is per process** | When a model rejects a parameter (for example `temperature`), the adapter disables it only in that process, and each process learns it again after a restart. Set `LLM_SUPPORTS_TEMPERATURE` / `LLM_SUPPORTS_JSON_SCHEMA` to make it permanent. |

## Assumptions

- Evaluation happens locally with Docker. AWS is the target platform but is not required to evaluate.
- One org per user. Content is English. Amounts are INR, USD or EUR.
- Contacts are synthetic. Nothing is scraped from LinkedIn or elsewhere.
- Email is the only channel actually sent. Other channels are deep links with manual logs.

See also the [changelog](/docs/changelog) and the [decisions](/docs/decisions).
